# Facial

基于 WebGPU 的网页版 MMD 渲染器

在浏览器里打开 PMX / PMD 模型、VMD 动作和音乐。动作、表情、镜头、灯光、自阴影按 MMD 的规则计算；刚体物理是自带的位置动力学解算器（纯 TypeScript，无 WASM）；可以用 WGSL 写三渲二和后期 shader，烘焙物理和布料，把整个场景存成一个工程文件，或导出视频。

## 特性

- **格式**：PMX 2.0 / 2.1、PMD（按 MMD / PmxEditor 规则转换为 PMX）、VMD（骨骼 / 表情 / 镜头 / 灯光 / 阴影 / IK 开关）、文本格式 DirectX `.x` 配件与舞台；贴图 PNG / JPG / TGA / BMP / SPH / SPA / DDS（DXT1/3/5、BC7）；全景图背景；mp3 / wav / ogg / m4a / flac 音频。
- **动作**：贝塞尔插值、变形阶层、付与、CCD IK（膝盖平面解）；全部表情类型（顶点 / UV / 骨骼 / 材质 / 组合）；GPU compute 蒙皮（BDEF1/2/4、SDEF、QDEF）。
- **渲染**：MMD 材质（sphere、toon、描边、双面）、3 级级联自阴影（MME full.fx 公式）、地面阴影、平行投影镜头、4× MSAA、泛光 / 景深 / ACES 色调映射、超采样。
- **灯光**：主光的方向 / 颜色 / 强度，最多三盏补光 / 发丝光，影棚三点光等预设，或跟随 VMD 的灯光关键帧。
- **物理**：XPBD 刚体解算器，三种刚体模式、6DOF 关节、球 / 盒 / 胶囊碰撞，默认在 Web Worker 中运行；可烘焙成确定性结果并导出为 VMD 关键帧；布料解算（裙子、袖子逐顶点模拟）；蒙皮后的布料防穿模。
- **三渲二**：自定义材质 shader（WGSL），有镜头深度预绘、固定粗细的轮廓光、刘海投影、眉眼透发、自定义描边色，以及自动生成的色条 / 光照图 / 脸部阴影图；附带星铁风格、双色卡通、皮肤次表面散射等示例。
- **后期 shader**：整幅画面的 WGSL 效果，可读取颜色、深度和材质数据。
- **场景**：多模型、按材质显示 / 隐藏部件、模型摆放、不同体型角色的动作 / 镜头缩放、时间线（关键帧、音频波形、区间循环）。
- **导入导出**：拖入文件夹 / zip（Shift-JIS / GBK 文件名也能识别）；导出模型 zip、动作 / 镜头 VMD（可按区间裁剪）、MP4（H.264 + AAC）或 PNG 序列；一个 `.mmdproj.zip` 工程文件保存整个场景。

## 运行

需要支持 WebGPU 的浏览器（最新版 Chrome / Edge / Safari / Firefox）。

```sh
pnpm install
pnpm dev          # http://localhost:5173
pnpm test         # 单元测试
pnpm build        # 类型检查 + 打包
```

开发用 URL 参数：`?model=<pmx 地址>&motion=<vmd 地址>&audio=<音频地址>`；`MMD_SAMPLE_DIR=/path/to/models pnpm dev` 会把该目录挂到 `/samples/`。

## 使用

舞台铺满整个窗口，菜单、场景面板、时间线浮在上面。右上角可分别收起场景面板 / 时间线、打开「显示与物理」设置和性能信息；按 H 隐藏全部界面只看舞台。

**导入**（菜单或直接拖入，可混合一次拖入）
- 模型：文件夹、PMX / PMD、zip。一次找到多个模型时会弹出选择框。场景可以有多个模型，场景面板里点选「当前模型」，可单独显示 / 隐藏 / 移除。
- 动作 VMD：骨骼 / 表情部分应用到当前模型（与模型一起拖入时应用到新模型），镜头 / 灯光 / 阴影部分进入场景的镜头轨道。多个 VMD 按关键帧合并（同一帧上后导入的覆盖先导入的，和 MMD 一样）。面板里的「动作用到的骨骼 / 表情」只统计真正有变化的轨道，悬停可看模型缺少哪些。
- 镜头 VMD、音频、2:1 全景图背景（jpg / png / webp）、文本格式 `.x` 配件 / 舞台（PMX 舞台直接当模型导入）。
- MMD 的 `Data` 文件夹（`toon01–10.bmp`）会替换内置共享 toon，并存进 IndexedDB。

**场景面板**
- 部件：「部件 → 显示 / 隐藏…」按材质勾选（帽子、外套、鞋子……）。隐藏的材质不画、不描边、不投影，物理照常。
- 体型不同的角色：模型的「位移 ×」按腿长缩放动作里的位移（步幅、重心高度），镜头的「身高 ×」「抬高」按身高调整注视高度和距离。「按腿长 / 按身高」以标准 MMD 模型（腿长约 9.6、头部高度约 17）为基准估算倍率。
- 模型位置 / 水平旋转、辅助贴图、烘焙物理、自定义 shader 也都在这里。

**灯光**（显示与物理 → 灯光）：主光决定明暗、toon 和投影，可改方向、高度、颜色、强度，或「跟随动作灯光」用 VMD 里的灯光关键帧；另外最多三盏附加灯，每盏可选「补光」（从那一侧柔和地照亮暗部）或「发丝光 / 轮廓光」（从背后打，只亮在边缘和发丝上）。预设：MMD 默认、影棚三点光、侧逆光、柔光、夕阳。MMD 会把材质的环境色（一般 0.5）加到主光颜色上再截断，所以带颜色的主光要调得暗一些才有色调。

**导出**
- 当前模型 → zip：模型文件 + 用到的贴图 + 作者的说明 / 使用规则文件，保持原目录结构；PMX 按原字节写出，PMD 转换为 PMX。
- 动作 / 镜头 → VMD：可只导出播放区间并把区间起点作为第 0 帧；区间边界落在曲线中间时会插入关键帧并精确切分贝塞尔曲线。未修改的关键帧原样写出。骨骼 / 表情名写成 Shift-JIS，没有的字写成 `?` 并提示。
- 视频：逐帧离线渲染，MP4（H.264，可带音频）或 PNG 序列 zip，可选分辨率、30 / 60 fps、只导出区间。

**工程**（文件 → 保存 / 打开，⌘S / ⌘O，或直接拖入 `.mmdproj.zip`）：一个 zip 保存各模型（原始字节）、动作、镜头、音频、背景、shader、辅助贴图、物理烘焙，以及当前帧、播放区间、视角、显示 / 物理 / 灯光设置。

**物理烘焙与布料**（场景面板 → 当前模型 →「烘焙物理…」）：后台 Worker 按 30 fps 把整段物理算一遍并记录，之后播放直接读取，结果确定、任意拖动 / 倒放都不需要重置；可同时勾选按布料解算的材质。烘焙结果存进工程，也可导出为 VMD 关键帧。详见 [docs/physics.md](docs/physics.md)。

**时间线**：显示镜头、当前模型骨骼 / 表情的关键帧和音频波形；点击 / 拖动跳转，滚轮滚动，⌘ / Ctrl + 滚轮缩放，双击标尺显示全部。播放区间用输入框、`[` `]` 按钮或 I / O 键设置，标尺上可拖动区间边缘。

**快捷键**：空格 播放 / 暂停 · ← → 逐帧（Shift ±10）· Alt + ← → 上 / 下一个关键帧 · Home / End · I / O 设区间 · L 循环 · R 重置物理 · H 隐藏界面 · ⌘S / ⌘O 保存 / 打开工程。视图：左键旋转，右键 / Shift + 左键平移，滚轮缩放；右下角坐标轴点击切换视角。

## 自定义 shader

用 WGSL 写，从「效果」菜单加载或把 `.wgsl` 文件拖进窗口。材质 shader 定义 `fn shade(s: Surface) -> vec4f` 替换一个模型的着色，后期 shader 定义 `fn effect(uv: vec2f, color: vec3f) -> vec3f` 处理整幅画面；写错时显示出错的行号并继续用原来的着色。`public/shaders/` 里的示例也在「效果」菜单里。完整接口见 [docs/shaders.md](docs/shaders.md)。

## 架构

坐标系全程使用 MMD 原生的**左手系**，视图和投影矩阵也是左手的。PMX / VMD 数据原样使用，不做 Z 翻转，也不改四元数符号。

每帧的数据流：
```
CPU  VMD 采样 → 表情展开（组合 / 骨骼 / 材质） → 骨骼解算：物理前阶段（变形阶层、付与、IK）
      → 物理：把骨骼姿势发给 Worker，套用上一帧算好的物理骨骼（相对父骨骼）→ 物理后阶段
      └→ Worker 线程：刚体解算（位置动力学），返回物理骨骼的「相对父骨骼」变换（缓冲区转移，不复制）
      └→ writeBuffer：骨骼矩阵 + 四元数、morph 权重、材质 uniform
GPU  compute：顶点 morph + UV morph + 蒙皮（BDEF1/2/4、SDEF）→ 蒙皮后顶点缓冲
      prepass：用了材质 shader 时，从镜头画一遍深度 + 材质种类（屏幕空间的轮廓光、刘海投影读它）
      shadow：光源正交投影的深度 pass（Render Bundle，复用同一份蒙皮结果）
      render：Render Bundle 重放（主 pass + 描边 pass + 眉眼透发 pass），4× MSAA，3×3 PCF 自阴影
```

## 实现说明

- 内置共享 toon 来自 three.js MMDLoader（MIT）。toon07–10 是纯白的，与 MMD 原版一致。
- 自阴影 VMD 的「距离」v（0–9999，默认 8875）换算成阴影范围 (10000 − v) / 10 个单位；MMD 没有公开确切公式，这是近似。模式 1 和 2 不作区分。没有自阴影关键帧时，范围按镜头里模型的位置自动决定。
- sphere 子贴图按「乘到颜色上」处理（MMD 的子贴图没有公开的混合公式）。
- `.x` 配件按 MMD 放大 10 倍；光照是近似：环境项 = 漫反射 × 灯光 + 自发光，受光面再加 N·L × 漫反射 × 灯光。帧动画、顶点色不读取。
- PMD 转换：膝盖隐式 IK 限制、IK 角度 ×4、基准表情、alpha < 1 双面、0.98 不投影、刚体相对位置。
- VMD 的骨骼 / 表情名最长 15 字节（Shift-JIS），MMD 会从中间把字截断。更长的模型名按同样的截断形式匹配；被截掉一半的字原样保留，导出时逐字节写回。
- 描边宽度按屏幕像素计算（与 saba 相同）。
- 物理解算器、Worker 延迟、碰撞检测和布料的细节见 [docs/physics.md](docs/physics.md)。

尚未支持：时间线关键帧编辑；MME 效果文件（`.fx`，需要 HLSL 到 WGSL 的转换）；二进制 / 压缩格式的 `.x`、配件挂到模型骨骼上（`.vac`）；附加 UV2–4；PMD 类型 9（回転連動）骨骼。
