# 物理、烘焙与布料

## 刚体解算器

刚体物理不是 Bullet，而是按 Müller 等人 2020 年的「Detailed Rigid Body Simulation with Extended Position Based Dynamics」实现的位置动力学（XPBD）解算器，纯 TypeScript，无 WASM 依赖。代码在 `src/physics/`：`rig.ts` 从 PMX 建立静态设置，`physics-world.ts` 是每帧的子步循环，`solver/` 是求解器本身。

- 关节的角度 / 位移限制、钉点和接触都是对位置的直接投影，关节弹簧按 1/k 的柔度实现（刚度 k 的弹簧仍施加 k·x 的力）。因此极小的质量、10 万级的弹簧刚度、腿部深深插进裙子等情况都不会发散，只会被平稳地推回。
- 每帧的真实经过时间切成等长子步（≤ 1/240 s），子步之间「跟随骨骼」刚体（腿等）平滑扫过，而不是瞬移进裙子里。重力 (0, −98, 0)；暂停时头发 / 裙子仍会自然静止下来。
- 每个子步默认只做一遍约束求解；关节从身体一侧向末端依次求解，静止和一般动作下已经收敛。剧烈甩动时长链会被拉开，此时自动追加到最多 3 遍。实测（324 刚体模型）：静止约 1.9 ms / 帧，剧烈摆动约 4 ms / 帧。
- MMD 的语义照搬：「物理+骨骼位置」刚体钉在骨骼位置上只做旋转（MMD 的「ボーン位置合わせ」）；关节相连的两个刚体不互相碰撞；移动 / 旋转减衰是每秒损失的速度比例，减衰 1.0 的刚体不保留任何速度，只跟着关节走（Bullet 亦然）；摩擦、反弹按两刚体相乘。
- 碰撞检测：球、胶囊按芯线距离精确计算；胶囊与盒用黄金分割搜索胶囊轴上离盒最近的点，芯线穿进盒内时改用分离轴求最短推出方向；盒与盒用 15 轴分离轴测试，接触点取最深的顶点或最近的一对棱，每对刚体最多一个接触点。两两刚体每次测试会得到一个保守的间距，在两者合计移动不到这个距离之前不再重测，所以大多数候选对几乎不花时间。
- 刚体 / 关节欧拉角按 yaw-pitch-roll（Ry·Rx·Rz），与 babylon-mmd 一致；three.js 的 MMDPhysics 用的是另一种顺序。
- 载入时预热，跳转 / 循环时重置。刚体 / 关节线框按类型分别开关（跟随骨骼 蓝、物理 红、物理+骨骼 绿、关节 黄），GPU 绘制，叠加在模型上。

仍可能出现的穿模 / 抖动多来自模型本身：关节角度限制很窄（±4°～±20°）、裙子刚体首尾相连成环、没有任何关节的物理刚体（会自由下落）等，在 MMD 里也会有类似表现。遇到缠绕可按「重置物理」（快捷键 R）。

## Worker

物理默认在 Web Worker 中运行（「显示与物理」里可切换 Worker / 主线程 / 关闭；Worker 启动失败时自动退回主线程）。

- Worker 模式下物理结果晚一帧（流水线，主线程从不等待）。结果以「相对父骨骼」的形式返回，所以头发、裙子不会因为这一帧延迟而和身体脱开；切到「主线程」则同帧计算。
- Worker 模式会把姿势外推一帧再模拟，腿部等运动学刚体的位置误差实测降低约 80%，减少裙子与腿穿插。
- 视频导出时实时物理改在主线程按固定步长计算；不同次导出可能有细微差别，烘焙物理后则完全一致。

## 烘焙

场景面板 → 当前模型 →「烘焙物理…」。

- 在后台 Worker 里按 30 fps 把整段（或播放区间）的物理逐帧模拟一次并记录。之后播放直接读取：结果确定、与显示帧率无关，任意拖动 / 倒放都不需要重置物理，主线程几乎零开销。实测 324 刚体模型约 3.5 ms / 帧（16 秒动作约 2 秒烘焙），可随时取消。
- 「使用」开关可在烘焙结果与实时物理之间切换；动作改变后烘焙会自动删除（它只对应原来的动作）。时间线的「物理」行显示烘焙范围。
- 导出动作 VMD 时可勾选「包含物理烘焙」，物理骨骼写成关键帧给 Blender / UE 等软件用。按「骨骼末端可见位移」精简：精确 ≤ 0.4 mm、标准 ≤ 1.6 mm、紧凑 ≤ 4 mm。晃动的头发 / 布料几乎每帧都在变，文件较大（标准约 0.5 MB / 秒）。在 MMD 里播放这类 VMD 时请关闭物理。
- 工程文件会保存烘焙结果（原始数据，无损）。

## 布料解算

在「烘焙物理」对话框里勾选要按布料解算的材质（会自动勾上名字像裙子、袖子、披风的），烘焙时一起算，回放时这些材质的顶点用解算结果代替骨骼物理。

- 哪些点固定、和什么碰撞都从模型得出：绑在身体骨骼上的顶点是固定点（腰那一圈），绑在物理骨骼上的自由运动；碰撞体是模型自带的「跟随骨骼」刚体。
- 四个选项：软 ↔ 硬挺（抗弯）、垂顺 ↔ 保持裙形（像衬裙一样把布料拉回模型上的形状；调到最左是完全靠自重垂下）、飘逸 ↔ 厚重（空气阻力）、精度（每帧的求解步数）。
- 贴图接缝处断开的顶点会自动缝合；布料上没有任何固定点的零件（花边、挂饰）跟着最近的布面走，不单独模拟。
- 烘焙开头会让身体从静止姿势过渡到第一帧的姿势，布料跟着算，避免一开始就卡在腿里。
- 限制：布料不和自己碰撞；碰撞体是胶囊和球，不是身体网格；结果是每个顶点的位置，存不进 VMD，只能在这里回放和导出视频；数据量约每千个质点每秒 0.36 MB。

不烘焙时也有一层轻量的防穿模：蒙皮之后在 GPU 上把布料 / 头发的顶点从身体的「跟随骨骼」刚体里推出来（静止姿势不变形，最多推约 6 厘米）。

## 调参基准

```sh
PHYSICS_BENCH=1 MMD_SAMPLE_DIR=<含 PMX 的目录> pnpm test physics-bench
```

输出每个模型在静止 / 摆动下的每帧耗时、骨骼位移分位数和关节间隙，以及 Worker 外推前后的腿部姿势误差。
